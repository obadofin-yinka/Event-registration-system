# Event Registration System
## Mini Project
The Event Registration System is a web-based application designed to simplify event registration and management.

It allows users to register for events, submit their details, and submit their details, and manage event registration records efficiently

## Features
- User registration
- Event information
- Registration management
- Simple and user-friendly interface
